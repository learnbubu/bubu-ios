Bùbù sound lab: Correct

A touch brighter with the rhythm spiced up: swung, triplets, dotted, a held breath, a grace-note flourish, an early landing, and an echo answer. Same sound, same chord; only the timing changes. Rhythm speed (under Notes) speeds any of them up or slows them down.

The Bùbù set

One family, each with its own gesture: Correct climbs the chord, Combo goes 'ding-ding!', Goal is a 'ta-daa', Lesson complete is a little tune, Level up whooshes and runs, Milestone booms and blooms, Chest glitters down and pops, Fire relit whooshes into a warm swell.

Fire relit: options

No crackle any more. The set above uses option 7.

Wrong: five options

Low, short and muted, a soft 'bwomp' rather than a buzzer. The set above uses option 5.
